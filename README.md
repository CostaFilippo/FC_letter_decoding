# FC Letter Decoding

The main objectives of this project are:

- Perform letter decoding using neural population activity
- Evaluate decoding performance under different conditions
- Fit a mixed-effects model for the response times

## How to Run

All required data are provided in `Data/`. Notebooks must be launched from the
`Code/` directory so that relative paths (`../Data/`, `../Results/`) resolve.

Run the notebooks in the following order:

1. `1a_localization.ipynb`
2. `1b_units_and_behavior.ipynb`
3. `2a_singleNeuron_response_box.ipynb`
4. `2b_controlled_neuron_letter_decoding.ipynb`
5. `2c_letter_decoding.ipynb`
6. `2c_letter_decoding_over_time.ipynb`
7. `2e_permutation_tests.ipynb`
8. `2f_decoded_letter_confounds.ipynb`
9. `3a_heldout_letter_decoding.ipynb`
10. `3b_response_time_change.ipynb`
11. `3c_area_letter_decoding.ipynb`
12. `3c_controlled_area_letter_decoding.ipynb`
13. `3d_side_letter_decoding.ipynb`
14. `3e_size_letter_decoding.ipynb`
15. `3f_inout_letter_decoding.ipynb`

### Skipping long-running computations

Notebooks `2b`, `2c`, `3a`, `3c`, `3d`, `3e` and `3f` run many decoding
iterations. Their outputs are provided in
`Results/`.

## Analysis Pipeline

| Notebook | Content |
|---|---|
| `1a_localization` | Anatomical locations of units |
| `1b_units_and_behavior` | Unit counts and behavioural analysis (accuracy, response times)|
| `2a_singleNeuron_response_box` | Single-neuron responses; identifies letter-selective neurons |
| `2b_controlled_neuron_letter_decoding` | Letter decoding after excluding letter-selective neurons |
| `2c_letter_decoding` | Population letter decoding |
| `2c_letter_decoding_over_time` | Stage-resolved decoding (encoding, maintenance, retrieval) |
| `2e_permutation_tests` | Mixed-effects model of response time (Table 1), permutation test, probe-identity likelihood-ratio test, serial-position model |
| `2f_decoded_letter_confounds` | Tests whether letter decodability is explained by phonological features |
| `3a_heldout_letter_decoding` | Letter decoding with one participant held out |
| `3b_response_time_change` | Response-time change per letter with one participant held out |
| `3c_area_letter_decoding` | Decoding across brain areas |
| `3c_controlled_area_letter_decoding` | Area comparison with size-matched neuron subsets |
| `3d_side_letter_decoding` | Left vs. right hemisphere |
| `3e_size_letter_decoding` | Set size 4 vs. 6/8 |
| `3f_inout_letter_decoding` | IN vs. OUT trials |
