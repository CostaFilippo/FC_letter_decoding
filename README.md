# FC Letter Decoding

The main objectives of this project are:

- Perform letter decoding using neural population activity
- Evaluate decoding performance under different conditions
- Fit a mixed-effect glm for the response times

## How to Run

### Data

All required data files are already provided in the `Data/` directory. No additional download is needed.

### Running the notebooks

Notebooks must be launched from the `Code/` directory so that relative paths (e.g. `../Data/`, `../Results/`) resolve correctly:


Run the notebooks in the following order:

1. `1a_localization.ipynb`
2. `1b_units_and_behavior.ipynb`
3. `2a_singleNeuron_response_box.ipynb`
4. `2b_controlled_neuron_letter_decoding.ipynb`
5. `2c_letter_decoding.ipynb`
6. `2d_RT_INOUT.ipynb`
7. `3a_heldout_letter_decoding.ipynb`
8. `3b_response_time_change.ipynb`
9. `3c_area_letter_decoding.ipynb`
10. `3c_controlled_area_letter_decoding.ipynb`
11. `3d_side_letter_decoding.ipynb`
12. `3e_size_letter_decoding.ipynb`
13. `3f_inout_letter_decoding.ipynb`
14. `Table1_phonological.ipynb`

### Skipping long-running computations

Notebooks `2c`, `3a`, `3c`, `3d`, `3e` and `3f` run many decoding iterations (approx. 2 min per run with 6 cores) and save results to `Results/`. Pre-computed results are provided in `Results.zip`.

### Running the R model

`glm.R` fits the mixed-effects model for reaction times. It requires `Results/table_df.csv`, which is generated by `Table1_phonological.ipynb`.

## Analysis Pipeline

#### `1a_localization.ipynb`

- Determines anatomical locations of units

#### `1b_units_and_behavior.ipynb`

- Analysis of behavioral variables

#### `2a_singleNeuron_response_box.ipynb`

- Analyzes single neuron responses

#### `2b_controlled_neuron_letter_decoding.ipynb`

- Run letter decoding after excluding letter-selective neurons
- Reports the proportion of selective neurons per brain area

#### `2c_letter_decoding.ipynb`

- Implements population decoding models
- Trains classifiers to predict letters
- Evaluates decoding accuracy

#### `2d_RT_INOUT.ipynb`

- Analyzes the relation between response time and letter decoding accuracy

#### `3a_heldout_letter_decoding.ipynb`

- Examines letter decoding when holding out one subject

#### `3b_response_time_change.ipynb`

- Examines reaction times across conditions

#### `3c_area_letter_decoding.ipynb`

- Compares decoding across brain areas

#### `3c_controlled_area_letter_decoding.ipynb`

- Replicates the area comparison analysis using matched-size neuron subsets (HIP, AMY, EC)

#### `3d_side_letter_decoding.ipynb`

- Compares letter decoding accuracy between left- and right-hemisphere neurons

#### `3e_size_letter_decoding.ipynb`

- Compares decoding across set sizes

#### `3f_inout_letter_decoding.ipynb`

- Compares decoding across trial types

#### `Table1.ipynb`

- Builds the trial-level dataframe and fits a mixed-effects model of reaction time with decoding accuracy, trial type, set size, and probe letter as predictors
- Saves `table_df.csv` used by `glm.R`

#### `Table1_phonological.ipynb`

- Extends `Table1.ipynb` by adding phonological similarity predictors derived from German letter-name IPA features
- Computes within-string and probe–string cosine similarity, fits the extended mixed-effects model, and saves the results table

#### `glm.R`

- Fits a mixed-effect generalized linear model for the reaction time

## Results

The analysis produces:

- Decoding accuracy results
- Summary results of behavioral variables
- Mixed-effect linear model results for the reaction time
- Area- and condition-specific comparisons

Results are visualized in `Figures/` and archived in `Results.zip`.

Typical runs complete in minutes for notebooks 1a, 1b, 2a, 2b, 2d, 3b and for glm.R.

Notebooks 2a, 3a, 3c, 3d and 3e require multiple decoding runs. Each decoding run completes in around 2 minutes when using parallel processing (tested with 6 cores).
